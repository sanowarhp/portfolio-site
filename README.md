Personal portfolio site for Sanowar Hossain, full-stack web & e-commerce developer based in Bogura, Bangladesh.

**Live projects featured:**
- [Giftoria](https://giftoria-bd.com) — premium gift-box e-commerce system
- [Veloxa Digital](https://veloxa-digital-site.sanowarhp789.workers.dev) — digital agency brand

## Tech

Plain HTML, CSS and JavaScript. No build step, no framework, no dependencies.

## Structure

```
index.html
assets/
  css/style.css       # design tokens + all styles
  js/main.js           # nav toggle, gallery tabs, scroll reveal
  images/
    profile/            # hero + headshot photos
    giftoria/            # storefront + admin case-study screenshots
    veloxa/               # Veloxa Digital case-study screenshots
    favicon.svg
```

## Running locally

Just open `index.html` in a browser — no server or build step required.

## Deploy

Push to this repo and connect it to Cloudflare Pages (or any static host) with:
- Build command: none
- Output directory: `/`
